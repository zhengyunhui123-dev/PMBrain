# Brain First

1. Start with `recall` and `query` using `expand=false`.
2. Use `get_page` when the exact source text or full context matters.
3. Retry with `query` using `expand=true` only for a genuinely complex or unresolved question.
4. Distinguish retrieved evidence from inference, cite the relevant page slugs, and say when PMBrain does not contain enough evidence.
5. Do not write or change knowledge while using this read-first workflow.
