## PMBrain 1.5.17

- 点一次导入。原文和切块保存后就可以查看、用关键词搜索，并提示正在后台优化搜索。
- 任务中心显示一轮「优化搜索」，可以看到完成了多少份资料，也可以暂停和继续。暂停后，新导入的资料只记入待优化，不会自动开始。完全退出后，正在运行的会接着做，手动暂停的仍保持暂停。
- 选择仅关键词的资料不进入搜索优化。没有向量模型或向量接口失败时，已导入的资料仍然可用。
- 人物和概念整理不再挡住导入完成，仍由现有的后台整理处理。

## PMBrain 1.5.16

- 导入只写入原文和切块。向量化是任务中心里单独的任务，入库后自动开始。
- 向量化可以暂停，也可以继续。暂停保留已写入的向量和原文，继续只处理还没有向量的内容。
- 仅关键词导入不生成向量化任务。

## PMBrain 1.5.15

- 导入先把文件和切块写入知识库，关键词搜索马上可用，不再等向量接口返回。
- 需要向量时，向量化在后台继续，只处理本次新导入或更新的页面，以及这次整理出的实体页。
- 仅关键词导入不生成向量。向量化失败不删除已入库内容和原始资料。

## PMBrain 1.5.14

- 整理占用数据库时，显示当前任务、资料、阶段和已占用时间，以及其他请求等了多久。
- 对话列表改为摘要索引，正在生成的回答按增量刷新；离开页面后降低刷新，完整历史仍可恢复。
- 授权目录可以新建文件夹、复制选定文件，并重命名本次复制或新建的文件；不修改、不覆盖、不删除原始资料。
- 首页显示上次整理的时间、范围、新增或更新、失败内容和需要判断的事项。
- 内容质量按五项分开计分，开发回归题和未参与调优的独立题分开；不把 1.5.0 的旧结果当作当前通过。
- 数据库等待、执行超时、模型错误、预算停止和用户取消分开识别，原始错误文字仍保留。

## PMBrain 1.5.13

- 修复隔夜继续未完成任务时，将关机和暂停时间误算为本次超时的问题；保留原任务进度和累计费用。
- 数据库排队等待不占用 SQL 执行时限，排队期间仍可停止，实际执行超时继续受保护。
- 分别显示任务执行超时、数据库超时和模型连接失败的原因。
