## PMBrain 1.1.15

- 管理台移除已经失去作用的“导入与向量化”阈值设置；普通 Markdown、MCP 和外部输入仍由核心 500KB 内容安全规则保护，可信结构化 Office/PDF 继续按 Section → Chunk 处理；Admin 内嵌资源生成不再写入动态日期，避免跨 UTC 零点时被 CI 误判为生成物过期。
- 修复 PGLite 一次性命令已经完成但数据库关闭句柄卡住时，首次配置或 Admin 长时间停留在“处理中”的问题；Windows CI 现在会真实验证打包 Sidecar 连续上传 Markdown 和 PDF。
- 修复不同 Windows 构建环境生成 Admin HTML 空行不一致的问题，并同步更新只验证 Windows Desktop Runtime 的 CI 契约。
- 可信的大型 PDF、Word、PPT 和 Excel 文档不再因结构化正文超过 500KB 而整篇跳过向量化；普通 Markdown、MCP、Webhook 和远程输入仍保留原安全限制。
- 大文档按章节生成带文档名、章节路径和页码等定位信息的 Chunk，分批持久化向量；中断后可从已完成 Chunk 继续，仅修改章节时复用未变化的向量。
- 文档导入升级为本地结构化解析：PDF、Word、PPT 和 Excel 统一保留章节、列表、表格及页码、幻灯片、工作表定位。
- PDF 优先使用固定版本的本地 Rust 解析器，异常时自动回退到原有 `pdf-parse`，不会因结构化升级阻断既有导入。
- 导入页新增“结构化解析”和可选“图片内容识别”开关，并明确本地解析与可能调用视觉模型的边界。
- Windows Sidecar 内置并校验 PDF 原生库；修复打包环境 Excel 文件读取失败及无 BOM UTF-8 CSV 中文乱码。
- 新增结构化文档 V1/V2 检索 Benchmark 框架；真实私有文档语料与人工标注仍需在发布前补齐并运行。

## PMBrain 1.1.10

PMbrain桌面版本周更新汇总：

1. 设置中新增「普通模型调用」全局开关（默认关闭）。关闭后不再调用 DeepSeek 等聊天模型，向量化、语义搜索、混合搜索和快速维护仍可正常使用；开启后才可进行 AI 深度整理和 AI 会议整理。
2. 知识工作台「搜索」支持关键词搜索与语义搜索切换，默认关键词搜索，不依赖普通模型；「发送」仍用于 AI 意图处理。
3. 定时一键整理改为与「快速维护」同一套逻辑，每天自动维护更轻量，避免后台误跑深度整理消耗模型额度。
4. 知识整理模式名称更清晰：快速维护、AI 深度整理、AI 会议整理；关闭普通模型时，深度与会议入口会明确置灰并提示。
5. 新增任务中心，可查看导入、知识整理等后台任务进度，并支持安全取消；PGLite 忙碌时也会引导前往任务中心。
6. 软件更新支持展示本版本更新说明，并写入自动更新元数据；软件修复页可查看升级前数据库备份清单。
7. 修复 Ollama 本地普通模型偶发空回答；企微助手增加客服微信二维码，方便扫码咨询。
8. GitHub 发布收敛为 Windows 安装包与自动更新链路，安装与升级更专注本机桌面场景。
