## PMBrain 1.5.6

- 深度整理可提炼有来源的知识点、综合相关概念，并处理符合条件的原始对话；观点生成保持关闭。
- 知识提炼沿用普通模型，可配置阶段预算和自动整理方式；首次启用仅处理新增或变更资料。
- 未变化成果复用，写入失败保留待处理范围，概念更新保护人工正文和时间线。
- 整理结果显示跳过原因和剩余工作，搜索索引未完成可继续处理。

## PMBrain 1.5.5

- 新增或变更资料自动整理重要人物、组织、项目与概念，补充来源关联；复用已有实体和有效成果。
- 导入和维护在原任务中完成增量整理，失败可继续原任务，未变化资料不重复调用实体模型。
- 整理设置可调整自动实体开关、执行上限与费用；生成备份不递归整理，旧任务和已有知识保留。
- 修复有错误的阶段被跳过重试，以及服务报错被误判为运行环境缺失的问题。

## PMBrain 1.5.4

- 普通导入、快速维护和默认 Dream 不再额外启动完整实体摄入，保留原有同步、关系维护和向量更新。
- 旧自动实体任务暂停，历史成果保留；原维护任务可继续剩余阶段。明确指定资料的实体摄入仍可使用。
- 设置中可调整新整理任务的最长运行时间，自动任务与手动任务共用设置；继续旧任务保留原上限。

## PMBrain 1.5.3

- 修复整理写入失败并回滚后，同一任务继续处理时误报“页面在处理期间已改变”的问题。
- 保留对用户外部修改的冲突保护，原文、已保存事实与原有整理规则不变。

## PMBrain 1.5.2

- 修复后台任务停止或线程退出后，资源检查继续发消息导致知识库服务退出的问题。
- 数据库写入超时后沿用原有取消、回滚和恢复流程，任务状态保持可读，已完成资料保留，并可继续原任务。
- 更新 Windows 后台运行环境，改善连续整理和线程停止的稳定性，保留原有系统与 CPU 兼容要求。
