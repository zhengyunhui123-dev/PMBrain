## PMBrain 1.4.2

- 填好地址后会显示实际请求路径。仍只保存这一份地址。

## PMBrain 1.4.1

- 保存 API 密钥时，不再因为别的配置刚写过就报一串英文并拒绝保存。
- 拉取模型失败时，在选择模型窗口里用中文说明，例如密钥无效。
- 添加所选模型后，可以检测连接并启用服务商。

## PMBrain 1.4.0

- 编辑已有 API 密钥时会带上当前密钥。复制、编辑、删除在密钥框悬停或聚焦时出现，显示和隐藏按钮一直留着。
- 需要密钥的服务商删掉最后一把密钥时，会先确认，确认后停用。已添加模型的操作改为移上去再出现。
- 内置平台可以把 API 地址恢复成默认地址。新增 DMXAPI、七牛云 AI 推理和百川，各用官方文档里的一份 OpenAI 兼容地址。
