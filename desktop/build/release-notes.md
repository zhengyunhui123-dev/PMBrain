## PMBrain 1.4.51

- 普通模型调用恢复原有超时边界；实体识别的单次和子任务超时可分别配置，不再固定 8 分钟。
- 截断恢复受已知模型能力、剩余 Token 和费用限制，预留最终验收额度，并保留正常工具轮次。
- 用户停止、服务关闭和超时分别反馈，失败资料保留阶段、已用 Token 及上限。

- Windows 本地服务通过父子进程通道正常关闭，等待任务和数据库收尾后重启。

## PMBrain 1.4.50

- Qwen3、DeepSeek R、GLM 等思考模型识别时自动预留 32k 输出空间；截断后在原预算内加倍重试一次。
- 截断、超时、限流和 JSON 解析失败分别反馈，失败资料保留待处理，其他正常资料继续识别。

- 不支持工具的模型通过受限 JSON 复用原摄入工具和落库验收；中断后保留协议、消耗与已完成回执。
- 事实与 Atom 抽取同样处理截断，失败不再被标记为已完成的空结果。

## PMBrain 1.4.49

- 快速维护同步后的实体识别归入同一个任务，不再连续新建独立知识整理。
- 深度整理遇到其他整理占用时保持排队，等待后执行；未执行和实体验收失败不再显示绿色完成。
- 中断后继续原快速维护，保留已同步资料、识别凭据及已消耗预算，清理该任务遗留的执行锁。
- 快照容量恢复后继续时清除持久停止标记，旧执行租约不能再次暂停已恢复的任务。
- 独立导入仍保留自动识别，自动整理计划设置保持原有含义。

## PMBrain 1.4.48

- 快速维护自动同步本地新增、修改和删除的资料，不要求事先提交 Git。
- 默认开启同步后的本地 Git 提交，可在设置关闭；只提交本轮成功同步的内容，保留用户暂存内容，不自动推送。
- 快速维护与深度整理的新增关联可展开来源、目标、类型和依据，点击明细定位图谱连线。
- 中断后复用文件与提交凭据；已清理的关联和无法提交的文件保留明确说明。
