# 订单清单培训会议通知生成 Skill

用于生成“外贸订单+清单预警管理应用培训会议通知”类正式通知。

## Contract

- 输入为培训会议通知需求，先输出 Markdown 草稿，用户确认后再生成 docx。
- 需要写入项目模板时，保持会议通知和参会回执的结构完整。

## Anti-Patterns

- 不跳过用户确认直接生成最终 Word 文档。
- 目标文件被占用时停止并请用户关闭，不创建替代文档。

## Output Format

- 先给出完整 Markdown 草稿；确认后输出包含会议通知和参会回执的 docx。

## 查找模板

先检索 PMBrain 获取模板内容：

- 搜索关键词：`培训会议通知模板` 或 `订单清单培训会议通知模板`
- 页面路径：`项目模板/订单清单培训会议通知模板`
- 如果 PMBrain 不可用，按下面的默认结构生成。

## 内容结构

- 红头：重庆市商务委员会
- 标题：关于召开外贸“订单+清单”预警管理应用培训会议的通知
- 收文单位：各区县商务主管部门等
- 引言：说明应用背景、建设情况、培训目的
- 一、会议时间
- 二、会议地点
- 三、参会人员
- 四、会议议程
- 五、其他事项
- 落款：重庆市商务委员会、日期
- 附件：参会人员回执，独立一页

## 生成流程

1. 先输出完整 Markdown 草稿。
2. 等用户确认内容。
3. 用户确认后再使用 docx 工具生成 Word。
4. 如目标 Word 文件被占用，停止并请用户关闭文件后重试，不重新创建替代文档。
