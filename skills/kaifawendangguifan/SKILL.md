# 开发文档格式规范

用于生成或检查开发方案、技术方案、项目建设方案类 Word 文档的基础排版规则。

## Contract

- 输入为开发方案、技术方案或项目建设方案的排版需求。
- 只调整文档格式，不改变业务内容和段落含义。

## Anti-Patterns

- 不额外添加颜色、底纹、装饰样式或改变原文语义。
- 有现成模板时不得绕过模板另起一套格式。

## Output Format

- 输出检查或修改结果，明确标题、正文、表格使用的字体与字号。

## 规则

- 标题使用黑体，不额外加颜色。
- 正文使用宋体 12pt。
- 表格文字使用宋体 10.5pt。
- 除用户明确要求外，不添加装饰色、底纹或额外视觉样式。
- 只调整文档格式，不改变业务内容和段落含义。

## 使用方式

当用户要求“开发方案排版”“Word 字体规范”“技术文档格式统一”时，先确认是否已有模板；若有模板，优先按模板执行。没有模板时使用本 skill 的规则。
